# Senior Design IoT PCB
A 2-layer, STM32-based IoT condition-monitoring PCB developed as a hardware-design platform for comparing AI-assisted and human-led electronic design workflows.

The prototype is intended to explore environmental and mechanical condition monitoring in an aircraft-related context. It is not certified or approved for installation on an aircraft.

Project Status: Schematic development in progress. Hardware has not yet been fabricated or validated.

1. Project Objectives

Measure temperature, humidity, ambient light, motion, and mechanical vibration.

Process sensor readings using an STM32 wireless microcontroller.

Support USB-C power and USB 2.0 data connectivity.

Explore Bluetooth Low Energy (BLE) telemetry and optional data logging.

Evaluate design quality, PCB routing, debugging, and hardware testing in AI-assisted versus human-led engineering workflows.
